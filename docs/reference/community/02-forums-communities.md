# 5.2 论坛与社区

---

## 扫地机器人专项社区

### Roboter-Forum（德语）
- **网址**：https://www.roboter-forum.com/
- **语言**：德语
- **内容**：Valetudo 安装、Root 教程、固件讨论
- **关键帖子**：Roborock 各型号的 root 经验分享

### 4PDA（俄语）
- **网址**：https://4pda.to/forum/index.php?showtopic=881982
- **语言**：俄语
- **内容**：Roborock 系列刷机、root、语音包
- **关键帖子**：FEL 模式进入方法、固件版本对比

### Home Assistant Community
- **网址**：https://community.home-assistant.io/
- **语言**：英语
- **内容**：Valetudo 与 HA 集成、MQTT 配置
- **关键帖子**：Valetudo live maps, MQTT autodiscovery

### robot-rating.ru（俄语）
- **网址**：https://robot-rating.ru/
- **语言**：俄语
- **内容**：扫地机评测、固件教程、语音包替换

### mi-fan.ru（俄语）
- **网址**：https://mi-fan.ru/
- **语言**：俄语
- **内容**：小米设备维修和故障排除

## 嵌入式 Linux 社区

### Armbian Forum
- **网址**：https://forum.armbian.com/
- **语言**：英语

- **网址**：https://xdaforums.com/
- **语言**：英语
