## 扫地机器人核心项目

### Valetudo
- **仓库**：https://github.com/Hypfer/Valetudo
- **语言**：TypeScript/Node.js
- **Stars**：15,000+
- **说明**：扫地机器人去云端固件，支持 Roborock、Dreame、Viomi 等多品牌
- **对 Villy 的价值**：硬件信息、协议分析、架构参考

### Dustcloud
- **仓库**：https://github.com/dgiese/dustcloud
- **语言**：Python
- **Stars**：2,000+
- **说明**：小米智能家居 MITM 代理（已被 Valetudo 整合）
- **对 Villy 的价值**：硬件文档仓库（dustcloud-documentation）

### Dustbuilder
- **网站**：https://builder.dontvacuum.me/
- **仓库**：https://github.com/dgiese/dustbuilder-howto
- **说明**：在线定制扫地机器人 root 固件
- **对 Villy 的价值**：FEL 刷写流程、固件注入技术

### awesome-vacuum
- **仓库**：https://github.com/awesome-vacuum/awesome-vacuum
- **说明**：开源扫地机器人资源精选列表
- **对 Villy 的价值**：一站式资源索引

### VacuumTiger
- **仓库**：https://github.com/codetiger/VacuumTiger
- **语言**：C++
- **说明**：开源扫地机器人固件
- **对 Villy 的价值**：替代固件方案参考

### LibreRVAC
- **组织**：https://github.com/LibreRVAC
- **说明**：Free/Libre/Open-Source 扫地机固件
- **对 Villy 的价值**：另一个开源固件参考

### zvldz/vacuum
- **仓库**：https://github.com/zvldz/vacuum
- **说明**：Roborock Gen1/Gen2 固件构建器
- **对 Villy 的价值**：Gen1 专项工具
