## 候选 Linux 发行版

| 发行版 | ARMv7 支持 | 最小内存 | 优势 | 劣势 |
|--------|-----------|---------|------|------|
| Buildroot | ✅ | < 64MB | 极致轻量，完全定制 | 构建复杂度高 |
| Debian armhf | ✅ | ~128MB | 软件包丰富 | 体积偏大 |
| Alpine Linux | ✅ | < 128MB | musl libc，极轻量 | 生态兼容性 |
| Armbian | ✅ | ~256MB | 开箱即用 | 需适配 sunxi |
| Yocto | ✅ | 可定制 | 工业级 | 学习曲线陡峭 |

## 推荐方案

**阶段 2**：Buildroot → 最小可启动系统 + Debian armhf → 完整开发环境
